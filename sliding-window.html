Sliding Window

Two pointers sweep across a string to find the longest substring without repeating characters — expanding right, and jumping left only when it has to.

How it works

Sliding window keeps two pointers, left and right, marking the edges of a "window" over the array or string — instead of checking every possible substring from scratch (which would be O(n²) or worse), the window only ever moves forward.

This page solves "longest substring without repeating characters." right expands the window one character at a time. If the new character is already inside the window, left jumps forward past that character's previous occurrence — shrinking the window just enough to remove the duplicate, not resetting it entirely.

Because left and right each only ever move forward and never backward, the whole string gets scanned in O(n) total — each character is added to the window once and removed at most once.
