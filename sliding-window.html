Sliding Window

Two pointers sweep across a string to find the longest substring without repeating characters — expanding right, and jumping left only when it has to.

How it works

Sliding window keeps two pointers, left and right, marking the edges of a "window" over the array or string — instead of checking every possible substring from scratch (which would be O(n²) or worse), the window only ever moves forward.

This page solves "longest substring without repeating characters." right expands the window one character at a time. If the new character is already inside the window, left jumps forward past that character's previous occurrence — shrinking the window just enough to remove the duplicate, not resetting it entirely.

Because left and right each only ever move forward and never backward, the whole string gets scanned in O(n) total — each character is added to the window once and removed at most once.

Code
function longestUniqueSubstring(s):
    left <- 0                          // left edge of the current window
    seen <- {}                          // character -> last index it was seen at
    best <- 0                          // longest window length found so far

    for right from 0 to length(s) - 1:               // right edge expands one step at a time
        c <- s[right]
        if c in seen and seen[c] >= left:               // duplicate found inside the window
            left <- seen[c] + 1                            // jump left past the duplicate
        seen[c] <- right                                // record this character's newest position
        best <- max(best, right - left + 1)              // update the best length seen so far

    return best

function longestUniqueSubstring(s) {
  let left = 0;               // left edge of the current window
  const seen = new Map();      // character -> last index it was seen at
  let best = 0;                // longest window length found so far

  for (let right = 0; right < s.length; right++) {   // right edge expands one step at a time
    const c = s[right];
    if (seen.has(c) && seen.get(c) >= left) {          // duplicate found inside the window
      left = seen.get(c) + 1;                            // jump left past the duplicate
    }
    seen.set(c, right);                                // record this character's newest position
    best = Math.max(best, right - left + 1);           // update the best length seen so far
  }

  return best;
}

    Map<Character, Integer> seen = new HashMap<>();   // character -> last index seen at

    for (int right = 0; right < s.length(); right++) {  // right edge expands one step at a time

        if (seen.containsKey(c) && seen.get(c) >= left) {  // duplicate inside current window
            left = seen.get(c) + 1;                          // jump left past the duplicate
        }
        seen.put(c, right);                                // record newest position of c
        best = Math.max(best, right - left + 1);           // update best length seen so far
    }

    return best;
}
