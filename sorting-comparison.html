Sorting Comparison

Quicksort, merge sort, and heap sort race on the same array. Watch how differently each one moves through the data to reach the same sorted result.

How it works

All three sort the same array of numbers, but by different rules for which pair to compare or move next:

  • Quicksort picks a "pivot" value, then partitions the array so everything smaller goes left of it and everything larger goes right — then recursively sorts each side. Fast on average (O(n log n)), but a badly chosen pivot on already-sorted data can degrade to O(n²).
  • Merge sort splits the array in half repeatedly until each piece has one element, then merges pairs back together in sorted order. Always O(n log n), no matter the input — the cost is needing extra memory to hold the merged pieces.
  • Heap sort first arranges the array into a max-heap (a tree where every parent is ≥ its children), then repeatedly swaps the largest element (the root) to the end and shrinks the heap. Also guaranteed O(n log n), and — unlike merge sort — sorts in place.

Watch how differently they move through the same data: quicksort in sharp partitioned jumps, merge sort in clean halves, heap sort in a steady countdown from the top.
