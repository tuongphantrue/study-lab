Union-Find

8 elements, each starting as its own group. Union two of them together, or find the root of a group — and watch path compression flatten the tree as you go.

How it works

Union-Find (Disjoint Set Union) answers one question fast: are these two elements already connected? Every element starts as its own group of one, pointing to itself as its "parent."

find(x) follows parent pointers upward until it reaches an element that points to itself — the root of that group. Two elements are connected exactly when find gives the same root for both.

union(a, b) connects two groups by making one root point to the other. This is exactly what Kruskal's algorithm (on the graph-algorithms page) uses to check "would adding this edge create a cycle?" — a cycle would mean both endpoints already share a root.

Path compression is the optimization shown below: every time find walks up to a root, it rewires every node it passed through to point directly at that root. Future lookups for those nodes become instant instead of re-walking the same chain — this is why real-world union-find is nearly O(1) per operation.

Code
function find(parent, x):
    if parent[x] != x:                          // x is not its own root yet
        parent[x] <- find(parent, parent[x])      // path compression: point straight at the root
    return parent[x]                            // the group's representative

function union(parent, a, b):
    rootA <- find(parent, a)                    // find a's group representative
    rootB <- find(parent, b)                    // find b's group representative
    if rootA != rootB:                          // only merge if they're in different groups
        parent[rootA] <- rootB                    // attach one root to the other
class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))   # everyone starts as their own group (parent = self)

    def find(self, x):
        if self.parent[x] != x:                      # x is not its own root yet
            self.parent[x] = self.find(self.parent[x])  # path compression: point at the root
        return self.parent[x]                        # the group's representative

    def union(self, a, b):
        root_a, root_b = self.find(a), self.find(b)  # find each side's group representative
        if root_a != root_b:                          # only merge if in different groups
            self.parent[root_a] = root_b                # attach one root to the other
class UnionFind {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i); // everyone starts as their own group
  }

  find(x) {
    if (this.parent[x] !== x) {                         // x is not its own root yet
      this.parent[x] = this.find(this.parent[x]);         // path compression: point at root
    }
    return this.parent[x];   // the group's representative
  }

  union(a, b) {
    const rootA = this.find(a);   // find a's group representative
    const rootB = this.find(b);   // find b's group representative
    if (rootA !== rootB) this.parent[rootA] = rootB;   // merge only if different groups
  }
}

    }

    }

    void union(int a, int b) {

    }
}
