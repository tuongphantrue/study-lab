Bitwise-ops

Click any bit to flip it, pick an operation, and watch the result form one bit at a time — the same logic your CPU runs on every integer, just at 8-bit scale.

How it works

A number stored as bits is just a row of 0s and 1s, each position worth double the one to its right (128, 64, 32, 16, 8, 4, 2, 1 for 8 bits). Every operation here works on one column at a time, comparing only the two bits directly above each other — there's no carrying or borrowing like in normal addition.

  • AND — result bit is 1 only if both input bits are 1. Useful for "masking," i.e. clearing bits you don't want while keeping the rest.
  • OR — result bit is 1 if either input bit is 1. Useful for turning specific bits on.
  • XOR — result bit is 1 if the two input bits differ. Useful for toggling bits, and for spotting which bits changed between two values.
  • NOT — flips every bit of a single number: 0 becomes 1 and 1 becomes 0.
  • << / >> (shift left/right) — every bit slides one position over, and a fresh 0 fills the gap left behind. Shifting left by 1 doubles the number (same reason moving a decimal digit left multiplies by 10); shifting right by 1 halves it, discarding any remainder.
