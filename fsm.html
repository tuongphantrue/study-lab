Finite State Machine

A turnstile has exactly two states and two possible inputs. Feed it coins and pushes and watch it transition — the same states-plus-rules model that powers the regex engine on this site.

How it works

A finite state machine is a set of states plus a rule table saying "if I'm in state X and input Y arrives, go to state Z." At any moment the machine is in exactly one state, and every input either moves it to a new state or keeps it where it is — there's no memory beyond "which state am I currently in."

This page simulates a turnstile: two states (locked, unlocked) and two inputs (coin, push). Feeding a coin to a locked turnstile unlocks it; pushing an unlocked turnstile locks it again; a coin on an already-unlocked turnstile does nothing new, and pushing a locked one does nothing (it just stays locked).

This exact model — states plus a transition table — is also what's running underneath the regex engine on this site: a regex pattern compiles to an FSM, and matching a string is just feeding characters into it one at a time and watching which state it lands in.
