Segment Tree

A tree that pre-combines array ranges so range-sum queries take O(log n) instead of O(n). Build the tree, then query any range and watch it decide which nodes it can trust directly.

How it works

A plain array answers "sum of a range" in O(n) by adding everything up each time. A segment tree answers the same query in O(log n) by pre-combining ranges into a tree, at the cost of O(n) space and build time.

Building the tree is recursive: each leaf holds one array element, and every internal node holds the sum of its two children's ranges. The root ends up holding the sum of the entire array.

Querying a range walks down from the root: if a node's range sits entirely inside the query range, its precomputed sum is used directly and the tree doesn't need to go any deeper on that branch. If it partially overlaps, the query recurses into both children and adds their results. Only O(log n) nodes ever need to be visited because each level of the tree roughly halves the range being considered.
