Data-structures

The same handful of operations, four different shapes. Push a stack, enqueue a queue, insert into a linked list, or drop a value into a binary search tree.

How it works

  • Stack (LIFO) — only the top is ever touched. push adds a new top, pop removes it. Think of a stack of plates: you can only take from the top. This is exactly how a program's call stack behaves (see the recursion page).
  • Queue (FIFO) — added to the back, removed from the front, like a line at a checkout. enqueue appends, dequeue removes the oldest item. BFS uses a queue for exactly this reason.
  • Linked list — instead of one block of memory (like an array), each node stores a value plus a pointer to the next node. Inserting or removing at the ends is O(1) because nothing has to shift, unlike an array — the tradeoff is you can't jump to index k without walking through k nodes first.
  • Binary search tree — every node keeps the ordering rule "left child < me < right child." To insert a value, start at the root and go left or right depending on the comparison, repeating until you fall off the tree into an empty spot — that's where the new node goes. Because each step (usually) halves the remaining nodes, search/insert are O(log n) on a balanced tree.
