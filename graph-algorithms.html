Graph-algorithms

Same weighted graph, two different questions. Dijkstra finds the shortest path from one node to every other. Kruskal's finds the minimum-cost set of edges that connects every node with no cycles.

How it works

Dijkstra's algorithm keeps a "best distance found so far" for every node, starting at 0 for the source and infinity for everything else. Each round, it finalizes whichever unvisited node currently has the smallest known distance — that distance can never improve later, because every edge weight is non-negative, so nothing cheaper could still be found through an unvisited (therefore farther) node. It then "relaxes" that node's edges: for each neighbor, it checks whether going through the just-finalized node beats the neighbor's current best distance, and updates it if so. Repeat until every node is finalized.

Kruskal's algorithm takes a completely different approach to a different problem: it sorts every edge by weight, cheapest first, then walks through that list adding an edge as long as it doesn't create a cycle — i.e. as long as its two endpoints aren't already connected through edges already chosen. A quick union-find structure tracks which nodes are already in the same connected group. It stops once every node is connected, which happens after exactly (number of nodes − 1) edges are added.

function dijkstra(graph, source):
    dist[source] <- 0                        // zero distance to reach itself
    for each node != source: dist[node] <- infinity   // unknown distance initially
    priorityQueue <- {(0, source)}            // explore cheapest known distance first

    while priorityQueue is not empty:
        (d, node) <- extractMin(priorityQueue)  // pull the currently-cheapest node
        if d > dist[node]: continue              // a cheaper route was already found: skip

        for each (neighbor, weight) in graph[node]:   // check every edge out of node
            newDist <- dist[node] + weight             // cost of reaching neighbor via node
            if newDist < dist[neighbor]:               // found a cheaper route
                dist[neighbor] <- newDist                // record the improvement
                priorityQueue.insert((newDist, neighbor)) // re-check this neighbor later

    return dist   // shortest distance from source to every node

def dijkstra(graph, source):
    dist = {node: float('inf') for node in graph}  # unknown distance to every node
    dist[source] = 0                                # zero distance to reach itself
    pq = [(0, source)]                              # (distance, node), cheapest first

    while pq:
        d, node = heapq.heappop(pq)   # pull the currently-cheapest node
        if d > dist[node]:
            continue                    # a cheaper route was already found: skip stale entry

        for neighbor, weight in graph[node]:   # check every edge out of node
            new_dist = dist[node] + weight       # cost of reaching neighbor via node
            if new_dist < dist[neighbor]:        # found a cheaper route
                dist[neighbor] = new_dist          # record the improvement
                heapq.heappush(pq, (new_dist, neighbor))  # re-check this neighbor later

    return dist   # shortest distance from source to every node
function dijkstra(graph, source) {
  const dist = new Map();
  for (const node of graph.keys()) dist.set(node, Infinity); // unknown distance initially
  dist.set(source, 0);          // zero distance to reach itself

  const pq = [[0, source]]; // simple array used as a priority queue (distance, node)

  while (pq.length) {
    pq.sort((a, b) => a[0] - b[0]);   // re-sort so the cheapest entry is first
    const [d, node] = pq.shift();      // pull the currently-cheapest node
    if (d > dist.get(node)) continue;  // stale entry: a cheaper route already found

    for (const [neighbor, weight] of graph.get(node)) { // check every edge out of node
      const newDist = dist.get(node) + weight;            // cost via this node
      if (newDist < dist.get(neighbor)) {                 // found a cheaper route
        dist.set(neighbor, newDist);                        // record the improvement
        pq.push([newDist, neighbor]);                       // re-check this neighbor later
      }
    }
  }
  return dist; // shortest distance from source to every node
}

vector<int> dijkstra(vector<vector<pair<int,int>>>& graph, int source) {
    vector<int> dist(graph.size(), INT_MAX);   // unknown distance to every node
    dist[source] = 0;                           // zero distance to reach itself
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq; // min-heap
    pq.push({0, source});

    while (!pq.empty()) {
        auto [d, node] = pq.top(); pq.pop();     // pull the currently-cheapest node
        if (d > dist[node]) continue;             // stale entry: cheaper route already found

        for (auto& [neighbor, weight] : graph[node]) {  // check every edge out of node
            int newDist = dist[node] + weight;            // cost via this node
            if (newDist < dist[neighbor]) {               // found a cheaper route
                dist[neighbor] = newDist;                   // record the improvement
                pq.push({newDist, neighbor});                // re-check this neighbor later
            }
        }
    }
