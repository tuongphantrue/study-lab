Regex-engine

A simplified engine supporting literals, . (any char), * (zero or more of the previous token), and + (one or more). Watch it try to match the pattern against the string, position by position.

How it works

The pattern is first split into tokens — a plain character, ., or a character followed by a repeat marker (*/+). Matching then walks the tokens left to right against the string, one token at a time: a plain-character token must equal the current string character exactly, and . matches any single character.

A * or + token is where it gets interesting, because "zero or more" doesn't say exactly how many to take. This engine is greedy with backtracking: it first grabs as many repeats as it can, then tries to match the rest of the pattern against what's left. If that fails, it gives back one repeat and tries again with one fewer — repeating until either the rest of the pattern matches, or there are no repeats left to give back (at which point that whole attempt fails). That "grab everything, then give back one at a time on failure" is exactly why it's called backtracking.

Because the pattern isn't anchored to the start, the engine also retries the whole process starting from position 0, then 1, then 2, and so on — a match anywhere in the string counts as success, same as a plain .match() in most languages without a leading ^.

function match(text, pattern):
    if pattern is empty:
        return text is empty                    // both exhausted together: a full match

    firstMatches <- text is not empty and (pattern[0] == text[0] or pattern[0] == '.')

    if length(pattern) >= 2 and pattern[1] == '*':
        // zero occurrences, or one occurrence + retry
        return match(text, pattern[2:]) or                          // skip the starred token
               (firstMatches and match(text[1:], pattern))            // consume one, stay on it

    return firstMatches and match(text[1:], pattern[1:])   // consume one character from each
def is_match(text, pattern):
    if not pattern:
        return not text                          # both exhausted together: a full match

    first_matches = bool(text) and pattern[0] in (text[0], '.')  # does the first token match?

    if len(pattern) >= 2 and pattern[1] == '*':
        # zero occurrences, or one occurrence + retry
        return (is_match(text, pattern[2:]) or             # skip the starred token entirely
                (first_matches and is_match(text[1:], pattern)))  # consume one, stay on same token

    return first_matches and is_match(text[1:], pattern[1:])  # consume one char from each side
function isMatch(text, pattern) {
  if (pattern.length === 0) return text.length === 0;  // both exhausted: a full match

  const firstMatches = text.length > 0 && (pattern[0] === text[0] || pattern[0] === '.');

  if (pattern.length >= 2 && pattern[1] === '*') {
    // zero occurrences, or one occurrence + retry
    return isMatch(text, pattern.slice(2)) ||                    // skip the starred token
           (firstMatches && isMatch(text.slice(1), pattern));     // consume one, stay on it
  }

  return firstMatches && isMatch(text.slice(1), pattern.slice(1));  // consume from both sides
}

    boolean firstMatches = !text.isEmpty() &&
        (pattern.charAt(0) == text.charAt(0) || pattern.charAt(0) == '.');

    }

}

    if (pattern.empty()) return text.empty();   // both exhausted together: a full match

    bool firstMatches = !text.empty() &&
