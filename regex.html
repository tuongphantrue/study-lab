Regex-engine

A simplified engine supporting literals, . (any char), * (zero or more of the previous token), and + (one or more). Watch it try to match the pattern against the string, position by position.

How it works

The pattern is first split into tokens — a plain character, ., or a character followed by a repeat marker (*/+). Matching then walks the tokens left to right against the string, one token at a time: a plain-character token must equal the current string character exactly, and . matches any single character.

A * or + token is where it gets interesting, because "zero or more" doesn't say exactly how many to take. This engine is greedy with backtracking: it first grabs as many repeats as it can, then tries to match the rest of the pattern against what's left. If that fails, it gives back one repeat and tries again with one fewer — repeating until either the rest of the pattern matches, or there are no repeats left to give back (at which point that whole attempt fails). That "grab everything, then give back one at a time on failure" is exactly why it's called backtracking.

Because the pattern isn't anchored to the start, the engine also retries the whole process starting from position 0, then 1, then 2, and so on — a match anywhere in the string counts as success, same as a plain .match() in most languages without a leading ^.

supported syntax: literals, . any character, * zero-or-more, + one-or-more (applies to the token before it)
