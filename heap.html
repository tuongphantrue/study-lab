Heap / Priority Queue

A binary min-heap always keeps the smallest value at the root. Insert a value and watch it sift up; extract the min and watch the last element sift back down into place.

How it works

A binary min-heap keeps one rule true everywhere: every parent is smaller than or equal to both its children. That rule alone guarantees the smallest element is always sitting at the root — no searching required.

Insert adds the new value at the very next open spot (keeping the tree balanced), then "sifts up": as long as it's smaller than its parent, swap with the parent and repeat. That's O(log n) because it only ever travels up one path, the height of the tree.

Extract-min removes the root, moves the very last element into its place, then "sifts down": swap with whichever child is smaller, repeating until the heap rule holds again. Also O(log n) for the same reason.

The same array secretly represents the tree — a node at index i has children at 2i+1 and 2i+2, so no pointers are needed.

function insert(heap, value):
    heap.append(value)                          // add at the next open spot (keeps it balanced)
    i <- length(heap) - 1                        // start at the newly inserted position
    while i > 0 and heap[parent(i)] > heap[i]:    // while the new value is smaller than its parent
        swap(heap[parent(i)], heap[i])              // bubble it upward
        i <- parent(i)                              // continue checking from the new position

function extractMin(heap):
    min <- heap[0]                              // the root is always the smallest value
    heap[0] <- heap.removeLast()                 // move the last element into the root's spot
    siftDown(heap, 0)                            // restore the heap property from the top
    return min

function siftDown(heap, i):
    smallest <- i
    l <- 2*i + 1, r <- 2*i + 2                  // indices of the two children
    if l < size and heap[l] < heap[smallest]: smallest <- l   // left child is smaller
    if r < size and heap[r] < heap[smallest]: smallest <- r   // right child is smaller still
    if smallest != i:                            // a child was smaller than the current node
        swap(heap[i], heap[smallest])              // swap it up
        siftDown(heap, smallest)                    // keep sifting down from the new position

def sift_up(heap, i):
    while i > 0:
        parent = (i - 1) // 2          # index arithmetic for a binary heap stored as an array
        if heap[i] < heap[parent]:      # child smaller than its parent: violates heap order
            heap[i], heap[parent] = heap[parent], heap[i]   # bubble it upward
            i = parent                    # continue checking from the new position
        else:
            break                       # heap order restored, stop early

def sift_down(heap, i):
    n = len(heap)
    while True:
        smallest, l, r = i, 2*i+1, 2*i+2      # indices of the two children
        if l < n and heap[l] < heap[smallest]: smallest = l   # left child is smaller
        if r < n and heap[r] < heap[smallest]: smallest = r   # right child is smaller still
        if smallest == i: break                # no child smaller: heap order restored
        heap[i], heap[smallest] = heap[smallest], heap[i]   # swap the smaller child up
        i = smallest                            # keep sifting down from the new position
// JavaScript has no built-in heap — a minimal manual version:
class MinHeap {
  constructor() { this.heap = []; }

  insert(value) {
    this.heap.push(value);           // add at the next open spot (keeps it balanced)
    let i = this.heap.length - 1;     // start at the newly inserted position
    while (i > 0) {
      const parent = Math.floor((i - 1) / 2);   // index arithmetic for an array-backed heap
      if (this.heap[i] < this.heap[parent]) {     // smaller than its parent: violates order
        [this.heap[i], this.heap[parent]] = [this.heap[parent], this.heap[i]]; // bubble up
        i = parent;                                 // continue checking from the new position
      } else break;                                // heap order restored, stop early
    }
  }

  extractMin() {
    const min = this.heap[0];          // the root is always the smallest value
    const last = this.heap.pop();       // remove the last element
    if (this.heap.length > 0) {
      this.heap[0] = last;               // move it into the now-empty root
      this.siftDown(0);                  // restore heap order from the top
    }
    return min;
  }

  siftDown(i) {
    const n = this.heap.length;
    while (true) {
      let smallest = i, l = 2*i+1, r = 2*i+2;   // indices of the two children
      if (l < n && this.heap[l] < this.heap[smallest]) smallest = l;  // left child smaller
      if (r < n && this.heap[r] < this.heap[smallest]) smallest = r;  // right child smaller
      if (smallest === i) break;                  // no child smaller: order restored
      [this.heap[i], this.heap[smallest]] = [this.heap[smallest], this.heap[i]]; // swap down
      i = smallest;                                 // continue from the new position
    }
  }
}

static void siftDown(int[] heap, int i, int size) {
    while (true) {
        int smallest = i, l = 2*i+1, r = 2*i+2;   // indices of the two children
        if (l < size && heap[l] < heap[smallest]) smallest = l;  // left child smaller
        if (r < size && heap[r] < heap[smallest]) smallest = r;  // right child smaller
        if (smallest == i) break;                   // no child smaller: order restored
        int tmp = heap[i]; heap[i] = heap[smallest]; heap[smallest] = tmp;  // swap down
        i = smallest;                                 // continue from the new position
    }
}
