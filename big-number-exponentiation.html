Fast Exponentiation

Computing base^exponent the naive way takes exponent-many multiplications. Exponentiation by squaring does it in log(exponent) steps by walking the exponent's binary digits.

How it works

Computing base^exp the naive way multiplies base by itself exp times — O(exp) multiplications. For large exponents (cryptography routinely uses exponents hundreds of digits long) that's hopelessly slow.

Exponentiation by squaring uses one observation: base^exp can be built from base^(exp/2) squared, cutting the exponent in half at every step instead of subtracting one. That turns O(exp) multiplications into O(log exp).

In practice this is done by walking the exponent's binary representation bit by bit. Start with result = 1, and repeatedly square a running "base" value. Every time the current bit of the exponent is 1, multiply that squared value into the result. This mirrors exactly how binary numbers represent a sum of powers of two — each bit says "should base raised to this power of two contribute to the answer?"
