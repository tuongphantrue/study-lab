Recursion

Recursion is a function calling itself, with a stack quietly keeping track of every unfinished call. Watch the stack for fibonacci, and watch backtracking undo bad guesses in N-Queens.

How it works

Every recursive function needs two things: a base case that stops the recursion (here, fib(0) and fib(1) just return directly, no further calls), and a recursive case that calls itself on a smaller problem (fib(n) calls fib(n-1) and fib(n-2)). Each call gets pushed onto the call stack when it starts and popped off when it returns — that's the panel labeled "call stack (live)." A call can't finish until both of its own recursive calls have returned, which is why the tree branches out before it ever collapses back into an answer.

Naive fibonacci recomputes the same smaller values many times (fib(3) gets called separately inside both fib(4) and fib(5)), which is exactly the inefficiency the dynamic-programming page's memoization fixes.

N-Queens is backtracking: place a queen in the current row, then recursively try to place the next row. If a placement leaves no valid spot anywhere in a later row, the recursion returns failure, the queen gets removed ("backtracked"), and the algorithm tries the next column in that row instead. Nothing is smarter here than brute force with an early exit — it just abandons a branch the moment it's proven hopeless, instead of checking it all the way to the end.

    if n <= 1: return n              // base case: fib(0)=0, fib(1)=1, nothing to compute
    return fib(n - 1) + fib(n - 2)   // recursive case: sum of the two prior values

            if solveNQueens(row + 1, cols):  // recurse into the next row
                return true                   // downstream succeeded, bubble success up
            cols[row] <- -1               // backtrack: undo the placement, try next column
    return false                       // no column in this row worked

def solve_n_queens(row, cols, n):
    if row == n:
        return True   # every row has a queen placed: solution found

    for col in range(n):              # try each column in this row
        if is_safe(row, col, cols):    # no earlier queen attacks this square
            cols[row] = col              # place the queen here
            if solve_n_queens(row + 1, cols, n):  # recurse into the next row
                return True                          # success! bubble it back up
            cols[row] = -1               # backtrack: undo the placement, try next column

    return False   # no column in this row led to a solution

def is_safe(row, col, cols):
    for r in range(row):                                    # check every earlier row
        if cols[r] == col or abs(cols[r] - col) == row - r:  # same column or same diagonal
            return False
    return True
